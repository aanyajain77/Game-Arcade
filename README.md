# Game-Arcade
 Game Arena — A multi-game web app built with pure HTML, CSS &amp; JavaScript. Features Truth &amp; Dare, Rock Paper Scissors, Snake, and Guess the Number. Includes user authentication (Sign Up/Sign In/Forgot Password), localStorage, timers, scoreboards &amp; confetti. No frameworks. Just code. 
 
🎮 Game Arena
A fun, interactive multi-game web app built with pure HTML, CSS, and JavaScript — no frameworks, no libraries.

🕹️ Games Included
-🎭 Truth & Dare — Add players, pick a mode (Classic, Social, Embarrassing, Spicy), and take turns answering truths or completing dares. Features a timer, scoreboard, streaks, power-ups, voting system, and custom questions.
-✊ Rock Paper Scissors — Play against a friend or the CPU. Choose Best of 3, 5, or 7. Fully animated with round tracking.
-🐍 Snake — Classic arcade snake game with adjustable speed and grid size. Tracks your high score using localStorage.
-🔢 Guess the Number — Try to guess a secret number with difficulty levels (Easy/Normal/Hard) and a limited attempts mode.

🔐 Features
-User Authentication — Sign Up, Sign In, and Forgot Password system using localStorage. Stores name, age, email, gender, gamer tag, and experience level.
-Session Persistence — Stay logged in across page refreshes.
-Confetti Celebrations — Triggered on wins and completions.
-Fully Responsive — Works on desktop and mobile.

🚀 How to Run
-Download or clone the repo
-Open game-arena.html in any browser
-Sign up and start playing!
